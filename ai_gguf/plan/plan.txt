  P4 Details:
  - Per-target-layer rank-4 LoRA: A [n_embd, rank], B [rank, n_ff]
  - Applied after FFN up-projection: tmp += strength * B^T(A^T(ffn_input))
  - Target layers: middle 33% (auto: 37%-70% of model depth)
  - A initialized with N(0, 0.01), B with zeros → net zero initial effect
  - Persisted in LINT binary format (tag=3) alongside KAN and sparse masks
  - Can be warm-started from cached control vector direction vectors

  GR (Gated Residual) Details:
  - Per-layer scalar gate: x_{l+1} = x_l + alpha_l * F_l(x_l)
  - Separate gates for attention output and FFN output per layer
  - Values in [0, 2]: 0 = skip layer, 1 = default (no change), 2 = amplify
  - Cost: ~0.064ms/token for 32 layers, 256 bytes memory
  - Flash attention: fully compatible (gate is outside attention kernel)
  - Injected at end of build_attn (4 overloads) and build_ffn — works for ALL models
  - Gate values derived from control vector direction importance per layer:
    - High-importance layers (>60%): FFN boosted up to 1.4x, attn up to 1.2x
    - Low-importance layers (<25%): FFN suppressed to ~0.5x (skip redundant compute)
    - Middle layers: gate = 1.0 (no change)
  - Based on GateSkip (arxiv 2510.13876): 37.3% compute savings, 91.5% accuracy

  ALL INTERVENTIONS ARE RAM-ONLY — GGUF MODEL FILE IS NEVER MODIFIED

  Every system (A-G, GR, P4-P7) operates purely in RAM:
  - Control vectors, head scales, temperatures, norm offsets, sparse masks,
    KAN coefficients, hypernetwork LoRA, residual gates → llama_context (heap)
  - Injected into the compute graph at build time, applied during inference
  - The .gguf file on disk is READ-ONLY (mmap'd, never written to)
  - Model weights are shared (const), interventions are additive/multiplicative
  - On app exit or clearAll(), all interventions evaporate — base model untouched
  - P7 learning tunes KAN coefficients in RAM only — improvements are session-local
    unless explicitly persisted via save_intervention_state()
