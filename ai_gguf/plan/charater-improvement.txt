Runtime Model Behavior Engine — Full Intervention System

 Context

 We have full source control over llama.cpp (forked), the JNI bridge (ai_gguf), and the app (ToolNeuron). The goal: modify every aspect of
 a transformer's behavior at runtime through a single universal .personality file — no retraining, no per-model files. Every intervention
 point in the forward pass becomes a controllable knob.

 Reference: ai_gguf/plan/Hacking-Attention-at-Runtime.html — interactive guide covering all 8 intervention surfaces.

 Part A: Runtime Control Vectors (Activation Steering)

 Theory (Contrastive Activation Addition — Panickssery et al., ACL 2024):
 v_direction = mean(activations_positive) - mean(activations_negative)   // per layer
 h'_l = h_l + α × v_direction_l    // applied after FFN residual, before next layer
 Most effective at layers 30-70% depth. The direction captures a behavioral axis (warm↔cold) in the model's own representation space. α
 controls strength (practical ceiling ~15-20 before coherence degrades).

 Our approach: Store contrastive text prompts in .personality file. At runtime, run forward passes through whatever model is loaded,
 extract per-layer hidden states, compute mean difference → that's the steering vector for that model. Cache per model hash.

 Part B: Logit Bias Personality

 Theory: Direct modification of output logits before sampling. Adding bias b to token t's logit multiplies its probability by exp(b). +2.0
 ≈ 7.4× more likely, -2.0 ≈ 7.4× less likely.

 logits'[t] = logits[t] + bias[t]    // before temperature/softmax

 Text-based token lists in .personality, resolved to token IDs at runtime using the loaded model's tokenizer. llama.cpp already has
 llama_sampler_init_logit_bias().

 Part C: Attention Score Bias Injection

 Theory (from Hacking-Attention HTML + SpotLight paper):

 Standard attention: A = softmax(QK^T / √d_k + M)

 With bias injection: A = softmax(QK^T / √d_k + M + B)

 Where B[i,j] is a bias matrix. Since it's added pre-softmax, each entry acts as a log-space multiplier: exp(B[i,j]) times more/less likely
  to attend. +5 ≈ 148× amplification.

 Use case for characters: Boost attention to persona description tokens and recent emotional context. When the model generates, it "focuses
  harder" on the character definition → more consistent personality in long conversations.

 SpotLight approach (Venkateswaran & Contractor, 2025):
 ψ_current = Σ(A[i,j] for j in persona_span) / Σ(A[i,k] for all k)
 B[j] = log(ψ_target / ψ_current)  for j in persona_span
 Self-correcting: bias approaches zero when model already attends sufficiently.

 Part D: Head Rescaling

 Theory (arXiv:2601.04398, 2026 — Attention Head Intervention):

 Each attention head's output is multiplied by a scalar α before being added to the residual stream:
 x_{l+1} = x_l + Σ_h (α_h × head_h(x_l))

 - α = 1.0 — default (no change)
 - α = 0.0 — ablate (completely remove this head's contribution)
 - α = 2.0 — amplify (double this head's effect)
 - α = -1.0 — reverse (invert this head's contribution)

 Research finding: Suppressing just 32 toxicity-related heads reduced toxic generations by 34-51%. Behaviors ARE localized to specific
 heads.

 Use case: At first launch with a new model, probe heads to identify which ones correlate with personality traits. Store head importance
 scores. At runtime, rescale heads based on active persona sliders.

 D3. Head Probing (Runtime, One-Time)

 To identify which heads matter for personality:
 1. Run a neutral prompt through the model, capture head outputs
 2. Run a personality-charged prompt (warm/formal/etc.), capture head outputs
 3. For each head: importance[l,h] = ||output_personality - output_neutral||
 4. Top-K heads per axis are the "personality heads"
 5. Cache the head importance map per model hash

 This uses the same activation capture infrastructure from Part A.

 Part E: Attention Temperature (Per-Head Sharpness)

 Theory (from Hacking-Attention HTML, Section 7):

 Standard: A = softmax(QK^T / √d_k)

 With per-head temperature: A = softmax(QK^T / (√d_k × T_h))

 - T < 1 → sharper, more peaked → model focuses on fewer tokens
 - T > 1 → flatter, more uniform → model attends more broadly
 - Different T per layer: early layers benefit from broad attention (context building), later layers from sharp (extracting specific
 patterns)

 Verification

 1. Control vectors: Warmth=+1.0 vs -1.0 → verify tonal difference
 2. Logit bias: Warmth tokens appear more/less frequently
 3. Attention bias: Long conversation (50+ turns) → character stays in persona with bias ON vs drifts without
 4. Head rescaling: Probe heads → amplify top personality heads → verify stronger personality signal
 5. Attention temperature: Sharper late layers → verify more focused/consistent outputs
 6. Cross-model: Load different model → same .personality → all systems recompute and cache → works
 7. Emotional steering: Happy messages → mood tracker shifts → all 5 systems adjust simultaneously
